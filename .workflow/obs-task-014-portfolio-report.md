# OBS-014 组合层优化（多策略资金分配） · 测试报告

> 分支：feature/obs-012-opt-apply（承接 OBS-012） · 日期：2026-10-07 · 状态：VERIFIED

## 1. 交付内容
| 产物 | 说明 |
|------|------|
| `PortfolioOptimizerService` | 组合成员各跑真实回测 → 取每 bar 权益收益序列 → 权重分配 |
| 分配方法 | **EQUAL** 等权 · **RISK_PARITY** 反波动率（1/σ 归一） · **MAX_SHARPE** 单纯形网格（步长可配，成员≤4 防爆） |
| 输出 | 各成员年化收益/波动/夏普/权重；组合年化/波动/夏普；**等权对照夏普**（同口径） |
| API | `POST /api/backtest/portfolio-optimize` |
| 前端 | 回测页「组合优化」卡片：成员（symbol:fast:slow）、方法选择、权重表 + 组合指标 |

## 2. 实测（真实 BTC_USDT + ETH_USDT，199 bars）
| 方法 | 权重 | 组合夏普 | 等权对照 | 备注 |
|------|------|---------|---------|------|
| EQUAL | 0.5 / 0.5 | -4.2293 | -4.2293 | 等于对照（口径一致） |
| RISK_PARITY | BTC 0.027 / ETH 0.973 | -6.4163 | -4.2293 | 组合波动 0.0010（vs 等权 0.0105，显著降低） |
| MAX_SHARPE | BTC 1.0 / ETH 0.0 | **-4.0946** | -4.2293 | 网格寻优不劣于等权 |

（窗口内真实行情下跌 → 夏普为负，如实呈现。）

## 4. 说明
- 收益序列取回测 `snapshots.totalAsset` 差分；年化因子按 1h（24×365）。
- 统一夏普计算口径（修复等权对照舍入偏差）。
- 成员上限 4（网格防爆）；可扩展为更多成员时改用解析优化。

## 5. 结论
组合层优化可用：多策略权重（等权/风险平价/最大夏普）与组合指标、等权对照，前端一键使用。
