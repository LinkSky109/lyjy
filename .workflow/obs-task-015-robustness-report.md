# OBS-015 优化稳健性检验（防过拟合） · 测试报告

> 分支：feature/obs-015-robustness · 日期：2026-10-07 · 状态：VERIFIED

## 1. 交付内容
| 产物 | 说明 |
|------|------|
| `POST /api/backtest/optimize/robustness` | 多标的稳健性检验：**样本内寻优（train 70%）→ 样本外验证（test 30%）** + **多折稳定性**（连续子窗口各自寻优） |
| 指标 | 样本内/外最优参数与收益、**退化率**（(oos−train)/|train|）、折间**参数稳定性**（最频繁参数命中率）、结论 `ROBUST / OVERFIT_RISK / INSUFFICIENT_DATA` |
| 前端 | 回测页「稳健性检验」卡片：训练占比/折数 → 结论标签 + 样本内外对比 + 各折表 |
| 复用 | `optimizeWindow(ticks, ...)` 窗口寻优（复用网格评估/目标排序） |

## 2. 关键缺陷修复（本次发现）
**`BarTicksMapper` 未按时间排序**：ClickHouse `queryBars` 返回 `bar_time DESC`，而映射器直接展开 → **回测/优化/组合/稳健性全部跑在时间倒序数据上（等于使用未来数据）**。
- 修复：映射器内按 `barTime` 升序排序（对所有消费方生效）。
- 修复前后对照（BTC_USDT 稳健性）：折窗口从倒序变**升序**；结论从虚假 `ROBUST` 变为真实 **`OVERFIT_RISK`**（样本内 +0.255% → 样本外 −0.051%，退化 −120%）。

## 3. 实测（真实 BTC_USDT 1h，199 bars，train 147/test 63）
| 项 | 结果 |
|----|------|
| 样本内最优 | 5/20 · ret +0.255% |
| 样本外 | ret −0.051% |
| 退化率 | −1.2016（符号翻转） |
| 参数稳定性 | 0.25 |
| 结论 | **OVERFIT_RISK**（如实反映小样本过拟合风险） |
| 折窗口 | 升序 09-29 → 10-07（4 折最优参数各异） |
