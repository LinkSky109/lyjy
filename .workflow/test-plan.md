## 三、Java静态一致性检查项

| 检查项 | 方法 |
|--------|------|
| 服务依赖完整性 | 7控制器注入的服务均有Spring实现 |
| 方法签名一致性 | 控制器调用与服务方法签名匹配 |
| 模型字段完整性 | 实体字段与业务调用匹配 |
| ORM映射一致性 | @TableName与SQL表名对应，字段映射 |
| Mapper与表结构 | SQL建表脚本覆盖所有实体 |
| 死代码/缺陷扫描 | 未调用的不完整方法 |
