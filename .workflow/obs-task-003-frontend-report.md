## 3. 过程中发现的运行问题（运维记录）
1. **长运行后端进程病态**：运行数小时后，`/api/backtest/*` 请求长时间无响应（连接建立但无工作线程执行），而 `health` 与普通 GET 正常 → **重启后端进程解决**（单人运维：`pkill -f core-0.1.0-SNAPSHOT.jar && ./scripts/dev.sh up`）。建议后续给 `dev.sh` 增加 `restart` 子命令。
2. **`/api/backtest/run-async` 运行时挂起**（同步 `run` 秒回）：前端回测页因此改走**同步 run**（<1s 直接出结果，无需轮询）；`run-async` 记录为已知待查项。
