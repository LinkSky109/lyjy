## P2 验收要点（对齐补充需求）
- 监管报送数据准确率 100%；AML 大额/可疑监测命中即告警，报告可人工复核后报送。
- 审计/合规留痕不可篡改（WORM/区块链预留，本地以只增表+权限保证）。
- 策略水印可在源码泄露后溯源到作者与下载人。
- 风险预算占用监控延迟 < 1s；违规处置联动事中风控。
- 多租户：租户间数据完全隔离，越权访问被拒（接口 + SQL 兜底）。
- 容量：水位监控 + 自动扩容适配（无交易中断）。

## 实施节奏
每任务 = 一次「开发 → 测试 → 一致性」闭环，与 P0/P1 一致；完成后更新 `.workflow/context.yaml`。
