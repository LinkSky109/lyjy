## 3. 新增能力

- `settlement_batch` 批次状态机：CREATED/RUNNING/REVIEWING/CLOSED/FAILED。
- 同一交易日仅一个批次，差异清零后确认关闭。
- 当日成交笔数和金额汇总。
- 手续费和已实现盈亏从资金流水汇总。
- 资金对账：总额、可用、保证金。
- 持仓对账：按标的和方向比较数量和成本。
- 成交对账：笔数和成交金额。
- 差异容差默认 0.01，超出生成 OPEN 工单。
- 差异调账、确认关闭和重跑保护。
- 资金、持仓、成交、盈亏四类报表。
- 7 个清算 API 和 FUND_MANAGER/COMPLIANCE 权限。
