## 六、缺陷记录与闭环（累计 10 个，全部闭环）

| 缺陷ID | 模块 | 描述 | 严重级 | 处理 | 状态 |
|--------|------|------|--------|------|------|
| BUG-001 | OMS | processTrade 不完整死代码，调用 selectByOrderId(null) | 中 | 移除方法 | ✅ |
| BUG-002 | OMS | 连带未被调用的 updateFill | 低 | 移除 | ✅ |
| BUG-003 | OMS | TradeReport import 未使用 | 低 | 清理 | ✅ |
| BUG-004 | OMS | OrderStateMachine 缺 @Component，服务启动找不到Bean | 高 | 加 @Component | ✅ |
| BUG-005 | 全局 | 编译未开 -parameters，@PathVariable/@RequestParam 解析失败500 | 高 | pom编译插件开 parameters | ✅ |
| BUG-006 | 风控 | strategyId 为 null 时 ConcurrentHashMap NPE | 高 | null 兜底为 DEFAULT | ✅ |
| BUG-007 | OMS | 空幂等键直接报错，客户端无法下单 | 中 | 按请求内容 SHA256 自动生成幂等键 | ✅ |
| BUG-008 | 回测 | 引擎无策略信号源，回测0交易，链路不闭环 | 高 | 新增 BuiltInStrategy 双均线内置策略 | ✅ |
| BUG-009 | 回测 | 市价单时序错位(currentTick为null)且成交不经processTick丢失 | 高 | 市价单入队，processTick统一撮合返回 | ✅ |
| BUG-010 | 回测 | 胜率以"是否有成本"判定，致全部亏损、胜率失真 | 中 | FIFO买卖配对，按完整开平回合算真实盈亏 | ✅ |

每个缺陷修复后均重跑相关用例，最终全量 14 自动化 + 48 接口 + 冒烟链路通过，无回归。
